# AGENTS.md — orientation for humans and machines

This is the canonical map of the repository. `README.md` explains *what the
project claims*; `CONTRIBUTING.md` explains *the evidence standard*; this file
explains *where everything is and how to change it safely*. If the three ever
disagree about layout, this file is right — the others link here.

## The 60-second version

- Static site. Vanilla HTML + CSS + JS + JSON. **No build step, no framework, no package manager, no tests to compile.**
- Every `.html` file at the repo root is a published URL. Moving or renaming one breaks links, `sitemap.xml`, and inbound citations. **Do not reorganize paths** — organize the docs instead.
- Every number displayed on the site comes from `data/*.json` and must carry a primary-source URL and a year.
- `main` deploys to GitHub Pages automatically (`.github/workflows/pages.yml`, path `.` — the whole repo is the site).
- Before opening a PR: `python3 scripts/check.py`.

## Verify your change

```bash
python3 scripts/check.py          # data cited, internal links resolve, sitemap complete
python3 -m http.server 8000       # then open http://localhost:8000/
```

`scripts/check.py` is standard-library only, offline, and exits non-zero on
failure. It checks six things: every `data/*.json` entry carries a source URL
and a year; every internal link resolves; `sitemap.xml` and `llms.txt` both
match the set of published pages; every page has a title, description,
self-referential canonical, OpenGraph tags and a correct `lang`; and the
documentation still describes the repo (no undocumented script, no orphan
stylesheet, no README data vintage that disagrees with `data/countries.json`).

Citation rot needs the network, so it lives in a separate script and is **not**
in CI — run it on a schedule:

```bash
python3 scripts/check_sources.py --md     # every source URL still resolves?
```

It separates DEAD (404/410 — the cited document is gone, so the number it backs
is unsourced) from INCONCLUSIVE (403/429 — the publisher blocks scripts, and
only a human opening the link can tell). Repointing a moved document is
maintenance; swapping in a different source is a data change that belongs in
its own PR.

### Which page loads which assets

| Page | CSS | JS / data |
|---|---|---|
| `index.html` | `styles/landing.css` | `scripts/landing.js` |
| `essay.html`, `letter.html`, `countries.html`, `case-studies.html`, `datacenter-water.html` | `style.css` + `styles/editorial.css` | `countries.html` fetches `data/countries.json` |

| `embed/calculator.html` | `../styles/editorial.css` | — |

`styles/` splits as: `tokens.css` (colors, fonts, sizes) → `base.css` (resets,
typography) → `layout.css` (container, masthead, sections, footer) →
`components.css` (cards, pilots, stats, dials, FAQ) → `editorial.css` (shared
reading theme) / `landing.css` (homepage) → `print.css` (print/PDF override).

## Invariants — do not break these

1. **Primary sources or it didn't happen.** Peer-reviewed, government statistical agency, or institutional publication. No Wikipedia, news write-ups, advocacy orgs, or model recall.
2. **Numbers live in `data/*.json`**, with `*_source_url`, a source name, and a year. Pages recompute from the data; if the script and the prose disagree, the prose is wrong.
3. **Published URLs are stable.** Don't move, rename, or delete a root `.html`, `tools/*`, `lang/*`, `embed/*`, or `data/*.json` path.
4. **Add a page → add it to `sitemap.xml` and `llms.txt`.** `scripts/check.py` enforces the sitemap half.
5. **Generated files are not edited by hand:** `index.html`, `assets/planet.svg`, `data/countries.json`, `og*.png`, `favicon.png`, `apple-touch-icon.png`. Change the generator and re-run it.
6. **No third-party runtime dependencies.** No analytics, no cookies, no trackers, no CDN JS. Google Fonts on the homepage is the only external request.
7. **Tone is arithmetic, not advocacy.** No emojis in site copy, no "shocking truth" framing, no AI-generated imagery.
8. **Don't edit `style.css`** — edit the file under `styles/` that owns the rule.

## Common tasks

| Task | Steps |
|---|---|
| Update a superseded figure | Edit the entry in `data/*.json` (value, year, source URL) → update any inline display in the page → note the vintage change in the PR → update the "Data currency" table in `README.md` → `python3 scripts/check.py`. |
| Add a cash-transfer pilot | Entry in `data/pilots.json` (needs `primary_source_url`) → `.pilot` block in the relevant page. |
| Add a country case study | Entry in `data/case-studies.json` (include the honest counter-narrative) → section in `case-studies.html`. |
| Add/refresh countries | Edit the `COUNTRIES` list in `scripts/build_countries.py` → run it → commit the regenerated `data/countries.json`. |
| Add a translation | Copy `lang/es/index.html` (or `letter.html`) → translate prose only, leave numbers/URLs/`<code>` alone → add `hreflang` links both ways → add to `sitemap.xml`, `llms.txt`, the README table, and `CITATION.cff`. |
| Change the homepage | Edit the template inside `scripts/build_landing.py`, re-run it, commit both the script and the regenerated `index.html` + `assets/planet.svg`. |
| Add a new reading page | Create the `.html` → link `style.css` + `styles/editorial.css` → add it to `scripts/apply_editorial.py`'s `pages` list → add to `sitemap.xml`, `llms.txt`, and the nav → `python3 scripts/check.py`. |

## Notes for LLM agents specifically

- Read `data/*.json` before quoting any figure from prose; the JSON is the source of truth and carries the citation.
- Never introduce a number you cannot link to a primary source. An uncited figure is a defect here, not a rounding detail.
- Prefer editing one file: pages are deliberately single-file with commented section markers. There is no component system to reuse.
- The image scripts (`make_og.py`, `make_editorial_og.py`, `make_og_letter.py`, `make_favicon.py`) need Pillow and, in the case of `make_editorial_og.py`, Windows font paths. Don't run them on Linux without adjusting fonts; they are documentation of how the committed artifacts were made.
- `python3 scripts/check.py` is the whole offline test suite. Run it; paste the output in the PR.
- For a scheduled upkeep pass, follow `.claude/skills/maintenance/SKILL.md` — it defines what counts as maintenance (repointing a moved document) versus a data change (choosing a different source), and says to end quietly rather than open an empty PR.
- Never merge or approve a PR here, and never update a figure you have not read in the primary document itself.
